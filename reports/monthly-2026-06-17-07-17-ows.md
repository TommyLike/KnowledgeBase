## 六、关键发现与风险

### 发现

1. **实际活跃度远超本地 digests 记录**：API 数据 1,103 PR / 78 仓库 vs 本地 digest 411 PR / 26 仓库。digests 覆盖率仅约 37%。
2. **backlog 不是传统代码项目**：217 个 PR 中绝大多数是需求文档变更，主导者是 TangJia025。这更像是需求管理工具而非软件工程仓库。
3. **oss-map 是本月的「重磅」项目**：虽然 PR 数排第三，但代码变更量最大——+2,913 行 top 5 PR。licy666 + Devin-DC-Huang 在做大规模数据采集重构。**本地 digests 完全遗漏了这个项目。**
4. **CI 自动化程度高**：github-actions[bot] 贡献了 28 个 PR，主要是自动化的 runner 镜像更新。
5. **Agent 开发规范正在成型**：agent-development-specification 有 16 个 PR，这是一个新方向。

### 风险

| 风险 | 严重度 | 说明 |
|------|------|------|
| **bus factor 极高** | 🔴 严重 | flysky22222(22%) + TangJia025(12%) + licy666(6%) = 40%。三个项目各自单点依赖 |
| **backlog 伪活跃** | 🟡 注意 | 217 个 PR 主要是需求文档，不能反映工程产出 |
| **oss-map 数据质量风险** | 🟡 注意 | 单 PR 2,212 行改动，缺乏充分 review 可能引入数据质量问题 |
| **digests 覆盖不全** | 🟡 注意 | 本地 digest 仅覆盖了 37% 的实际活跃仓库，需要补充自动采集机制 |
| **机器人 PR 真实占比** | 🟢 可控 | github-actions 28 个 PR 是自动化维护，非问题 |
