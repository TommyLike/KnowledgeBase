# DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning

> Daya Guo, Dejian Yang, Haowei Zhang, Junxiao Song, et al. (DeepSeek-AI) · 2025 · arXiv:2501.12948

## 中文摘要
DeepSeek-R1 证明了纯 RL（无需 SFT 冷启动）可以让 LLM 自主发展推理能力。使用 GRPO + 可验证奖励 + <think> CoT，在 MATH 和 AIME 上达到了 o1 级别性能。核心贡献：(1) RL 能涌现推理，(2) GRPO 不需要 critic，(3) 开源了完整的训练流程和模型权重。
