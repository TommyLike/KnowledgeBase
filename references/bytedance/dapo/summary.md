# DAPO: An Open-Source Framework for Large-Scale LLM Reasoning via Reinforcement Learning

> Jiacheng Yu, et al. (ByteDance Seed) · 2025 · arXiv:2410.06584

## 中文摘要
字节跳动的开源 LLM 推理 RL 框架，解决 GRPO 的 vanishing advantage 和 reward hacking 问题。核心改进：(1) 动态采样（Dynamic Sampling），(2) 去掉 reference model 的 KL penalty，(3) decoupled clipping。在 AIME 2024 上，DAPO训练的 Qwen2.5-32B 达到 55.0（vs GRPO 的 50.3）。
