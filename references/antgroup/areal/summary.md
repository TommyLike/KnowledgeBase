# AReaL: A Large-Scale Asynchronous Reinforcement Learning System for Language Reasoning

> Ant Group RL Lab · 2025 · arXiv:2505.24298

## 中文摘要
蚂蚁的全异步 RL 训练系统。核心创新：将 LLM 推理（rollout）和模型训练完全解耦，消除同步等待。基于 slime 架构，支持 PPO/GRPO/DAPO/LitePPO/Dr.GRPO，从 1 节点扩展到 1000+ GPU。NeurIPS 2025。AReaL-boba²-8B 在 LiveCodeBench 上 63.0 超越同规模所有模型。
