## 关键特性变更

- **ArgoCD 现网校验升级为资源级别查询**: 校验粒度从应用级别下沉到单个 Kubernetes 资源级别（#1246, +216/-24），配合 kustomize 子目录搜索（#1253）和 namePrefix/nameSuffix 解析（#1250），修复了之前因资源名不匹配导致的漏检问题，显著提升部署校验的精准度和可靠性。
- **仓库白名单防 LLM 幻觉机制**: 从 `.gitmodules` 提取真实仓库列表注入 prompt 模板，并在需求分析流水线中增加 Python 校验步骤，防止 LLM 在需求分析中引用已合并或不存在的仓库（#1212, +89/-0）。这是针对 AI 辅助开发中常见幻觉问题的工程化防御手段。
- **MindSpore PR Jenkins 日志查看器设计**: 完成需求分析与架构设计文档（#1145, ⚠️+994行），为 Jenkins 门禁日志在关闭匿名访问后的安全代理和流式查看提供完整方案，涵盖 Go/Gin 服务端、路径穿越防护、GitCode API 评论定位等关键设计点。
- **预览环境独立集群方案**: 输出预览环境优化设计文档（#1227, +438/-0），提出常驻预览集群 + 按 Issue 染色实例的架构，替代每次临时拉起完整环境的模式，大幅缩短预览环境就绪时间。
- **oss-map 新服务全流程接入**: 完成 OSS 全景地图服务从注册（#1184）、测试环境部署信息补全（#1207）到支持单仓库多子目录 Dockerfile 构建（#1215）的完整接入链路，打通了多 Dockerfile 子目录服务在 CI 中的构建与发布能力。
