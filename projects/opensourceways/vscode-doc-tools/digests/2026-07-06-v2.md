## 关键特性变更

- **新增**: 链接检查支持通过 HTTP 代理地址访问目标 URL。新增 `proxy` 配置项，链接有效性检查、资源存在性检查和 TOC 检查均可配置代理，解决企业内网或受限网络环境下无法直连外部链接的痛点。涉及 `shared` 包（请求层代理配置）、`checkers` 核心检查器、`docs-ci` 命令行工具和 VS Code 扩展的全链路改造。
- **发布**: 发布 v0.1.21 版本，包含上述代理支持特性。
