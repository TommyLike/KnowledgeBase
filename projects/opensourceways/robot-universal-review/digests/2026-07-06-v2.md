## 关键特性变更

- **重构**: 将 CodeOwner 评审检查逻辑从手动计算改为使用平台原生 CanMergeCheck 状态判断。`review_metric_helper.go` 从 45 行精简至 11 行（净减少 137 行），大幅简化了代码评审度量指标的检查流程。Gemini Code Assist 审阅指出 `a.prInfo` 为 nil 时存在空指针风险，建议增加默认回退消息。
- **新增**: 支持 merge message 扩展机制，在 `robot_helper.go` 新增 174 行业务逻辑及 964 行完整测试覆盖，允许自定义合并提交消息格式以适配 openEuler 基础设施（atomgit issues #431/#432）的合并需求。
- **修复**: 新增社区名（community name）参数传入，修复社区名称缺失导致配置解析不正确的问题，作为 merge message 扩展功能的配套修复。
