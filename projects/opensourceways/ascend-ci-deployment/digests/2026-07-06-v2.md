## 关键特性变更

- **新增 vllm-benchmarks CPU 32 核 Runner 体系**: 为 vllm-project 和 vllm-benchmarks 引入 linux-amd64-cpu-32 类型 runner，覆盖 hk-001 集群，支持 32 核 CPU + 128Gi 内存的纯 CPU 测试负载，同时扩展至 ARM64 架构（#912, #926, #934）。这是 CPU runner 从零到一的规模化部署。
- **新增 SGLang cn12-001 集群测试接入**: 在 cn12-001 集群上完成 SGLang 测试仓的全套 ArgoCD + Helm + ConfigMap 部署配置接入，包括 1483 行新增的集群配置（#913, #914, #915, #916），标志着 SGLang 测试基础设施覆盖新集群。
- **Vault + buildkitd 集成调试链**: 围绕 cpu-32-hk runner 的 Vault 证书注入和 buildkitd 构建缓存进行了密集迭代修复——包括从 job pod 到 ARC runner 的配置迁移、buildctl 权限问题、多架构 PVC 共享冲突、重复挂载清理等，共 8 个修复 PR（#922-#931）。
- **恢复 nv-action/vllm-benchmarks runner 全量配置**: 一次性恢复 4703 行 vllm-benchmarks runner 的 ArgoCD + Helm + Kustomize 全栈部署配置，涉及 gy-003、gy-005、hk-001、openmerlin-guiyang-006 四个集群（#921）。
- **监控告警规则清理与补全**: 移除无效的 CISchedulingBacklog 和 RunnerReplicaUnavailable 告警规则，同时将 Prometheus namespace drop 规则补全到各集群 patch 文件中（#910, #918）。
