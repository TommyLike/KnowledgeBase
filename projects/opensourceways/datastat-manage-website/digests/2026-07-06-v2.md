## 关键特性变更

- **ttfhw-confirm 问题确认工作流闭环**: 本周 ttfhw-confirm 页面经历密集迭代（#447 #449 #451 #457 #462 #464 #469），从问题类型筛选、列头可搜索多选、CSV 导出，到批量/单条提交 GitCode issue，形成完整的问题确认自动化闭环。确认时间统一改为北京时间（#457），默认使用贡献者场景（#462）。
- **蓝区(白盒)看板重构**: ⚠️ 将原看板拆分为「用户检查数据」和「采集数据维护」两个独立菜单，并修复贡献数据恒显示「校验失败」的长期 bug（#443, +3120/-1916），显著改善看板可用性。
- **开发者维度统计增强**: 开发者页面新增按仓库维度统计 D0/D1/D2 等级分布及详情下钻（⚠️ #421, +679/-14），等级详情下钻传递 chartStart 参数确保累计数据与图表对齐（#453）。
- **OSS Insight PR 预览功能**: 新增需求表 PR 预览功能，支持弹窗 iframe 预览报告，区分正式/预览链接（#442 #446），优化了报告链接列的视觉样式（#445）。
- **依赖安全修复**: echarts 从 5.6.0 升级至 6.1.0，修复 CVE-2026-45249 安全漏洞（#458）。
