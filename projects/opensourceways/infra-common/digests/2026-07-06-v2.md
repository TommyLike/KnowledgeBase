## 关键特性变更

- **Ingress API 版本升级**: 将 datastat-manage 测试环境的 Ingress 资源从 `extensions/v1beta1` 迁移至 `networking.k8s.io/v1`，并配置 `ingressClassName: nginx`，适配高版本 Kubernetes 集群，避免旧版 API 在未来版本中被移除导致部署失败。
- **域名证书监控扩展**: 在 infra-monitor 的证书扫描 ConfigMap 中新增 apig.osinfra.cn、easywhisperx.osinfra.cn、triton-transfer.osinfra.cn 等多个域名及 boostkit/hpckit/ospatch/hikunpeng/unifiedbus 子域名，扩大 TLS 证书到期监控覆盖范围。
- **Deployment 配置修复**: 删除 datastat-manage Deployment 中多余的 `nodeselecter` 字段并调整容器资源限制，修正因错误字段导致的调度问题。
- **命名空间规范化**: 调整 datastat-manage beta 环境的 kustomization 和 namespace 配置，统一部署命名空间。
