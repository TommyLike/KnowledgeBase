# ReMe

> ReMe: Memory Management Kit for Agents - Remember Me, Refine Me.

## 定位

ReMe 是 AgentScope 团队开源的 Agent 记忆管理工具包，为 LLM Agent 提供可扩展的长期记忆能力。团队将其纳入知识图谱作为上游贡献项目，关注其在记忆检索、记忆总结和跨会话上下文管理方面的设计思路，为 Ascend 生态的 Agent 框架建设提供参考。

## 项目介绍

ReMe（Remember Me）是一套面向 LLM Agent 的记忆管理基础设施，解决 Agent 在长对话和多轮交互中"遗忘"上下文的问题。它提供可插拔的记忆后端（向量数据库、图数据库、关系型数据库）、多种记忆检索策略（语义搜索、时间衰减、重要性加权），以及自动记忆总结与压缩机制，让 Agent 能够像人类一样"记住重要的事，忘掉不重要的细节"。

## 核心场景

- **长对话 Agent**：在多轮对话中保持用户偏好、历史决策和关键事实，避免 Agent 重复询问或丢失上下文。
- **个人助手**：跨会话记住用户信息、待办事项和交互历史，提供连续性的个性化服务。
- **知识工作 Agent**：在研究、编码、写作等长周期任务中，持续积累领域知识和中间结论。
- **多 Agent 协作**：多个 Agent 共享记忆空间，实现团队级别的上下文传递和知识沉淀。

## 技术要点

- **多后端记忆存储**：支持向量数据库（如 Chroma、FAISS）用于语义记忆、图数据库用于关系记忆、关系型数据库用于结构化事实存储，可根据场景灵活组合。
- **分层记忆架构**：将记忆分为短期工作记忆（当前会话）、长期情节记忆（历史交互摘要）和语义记忆（抽象知识），模拟人类认知模型。
- **记忆检索策略**：提供语义相似度搜索、时间衰减加权、重要性评分等多种检索策略，支持混合检索以平衡召回率和精度。
- **自动记忆总结**：通过 LLM 对历史交互进行周期性总结与压缩，将原始对话提炼为结构化记忆条目，控制记忆增长。
- **记忆生命周期管理**：支持记忆的创建、更新、合并、遗忘（过期删除），避免记忆膨胀导致检索质量下降。
- **Agent 框架集成**：提供与主流 Agent 框架（如 LangChain、AutoGen、AgentScope）的适配接口，可嵌入现有 Agent 工作流。

## 技术栈

- 语言：Python
- 记忆后端：Chroma / FAISS（向量）、Neo4j（图）、SQLite / PostgreSQL（关系型）
- LLM 接口：OpenAI API 兼容
- Agent 集成：LangChain、AgentScope、AutoGen
