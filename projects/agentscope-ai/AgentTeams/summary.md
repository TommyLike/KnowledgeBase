## 定位

AgentTeams 是 agentscope-ai 组织下的开源协作式多智能体操作系统（Collaborative Multi-Agent OS），面向需要透明编排、人机协同的多智能体场景。项目在知识图谱中属于 `agent-runtime/sandbox` 分类，标签为 `上游贡献`，表示团队向该项目进行上游代码贡献，而非主导维护。

## 项目介绍

AgentTeams 提供一个协作式多智能体运行时平台，核心理念是将多个 AI Agent 组织成一个可协作的"团队"，在人类监督者（human-in-the-loop）的参与下完成复杂任务。项目封装了智能体间的消息通信、任务分配、状态同步和结果汇总等基础设施，让开发者可以像定义组织架构一样定义 Agent 团队的协作模式。核心场景覆盖软件开发、自动化运维、知识和数据分析等需要多角色协同的工作流。

## 核心场景

- **多智能体协作开发**：多个 Agent 分别承担需求分析、编码、测试、Code Review 等角色，组成虚拟开发团队，在人类监督下完成端到端的软件交付流程。
- **自动化工作流编排**：将复杂业务流程分解为多个子任务，由不同特化的 Agent 分别执行，通过消息传递和状态机实现自动化流水线。
- **知识密集型任务协同**：多个 Agent 各司其职（信息检索、分析、总结、报告生成），协作完成需要跨领域知识的深度研究任务。
- **人机协同决策**：Agent 团队在执行关键决策点暂停并等待人类确认或指导，实现透明可控的 AI 辅助决策流程。

## 技术要点

- **角色化 Agent 定义**：每个 Agent 具备明确的角色描述、能力边界和输入输出契约，类似组织架构中的岗位定义，支持动态创建和销毁。
- **基于消息的协作协议**：Agent 之间通过结构化的消息通道（channel）进行通信，支持广播、点对点、任务分发等多种通信模式，保证协作过程的透明性和可追溯性。
- **Human-in-the-loop 机制**：关键决策节点设计人工审查断点，支持暂停、审批、修改和继续执行，确保 AI 行为处于人类可控范围内。
- **任务编排与状态管理**：内置任务分解、依赖管理、并行执行和状态追踪能力，支持复杂的多层嵌套工作流。
- **Python 生态集成**：基于 Python 构建，可集成各类 LLM API（OpenAI、Anthropic 等）、MCP 工具以及自定义工具链。
- **沙箱化 Agent 执行环境**：每个 Agent 在隔离的上下文中运行，保证安全性并避免状态污染，支持独立的环境变量和依赖管理。

## 技术栈

- 语言：Python（核心运行时），TypeScript（前端/工具链辅助）
- LLM 集成：OpenAI API、Anthropic API、多模型适配层
- 通信：结构化消息通道、WebSocket（实时协作）
- 存储：文件系统持久化（会话状态、任务结果）
- 工具链：pip 包管理、Docker 容器化部署

## 关联

- 上游：Agentscope（`agentscope-ai/agentscope`），AgentTeams 基于 Agentscope 框架构建，提供更高层的多 Agent 协作抽象。
- 同类项目：Microsoft AutoGen、LangGraph、CrewAI，均为多智能体协作框架，AgentTeams 的差异化在于 Human-in-the-loop 的深度集成和透明编排理念。
- 下游生态：可集成的 MCP 工具生态、各类 LLM API 提供者、Sandbox 运行时（Docker、E2B 等）。
