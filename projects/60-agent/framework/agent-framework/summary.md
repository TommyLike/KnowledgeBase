# microsoft/agent-framework

> [`microsoft/agent-framework`](https://github.com/microsoft/agent-framework) · 上游贡献 · 微软 AutoGen 继任者

## 定位
> 微软下一代 Agent 编排框架,AutoGen(59k★,现已维护模式)的官方继任。支持 Python+C# 双语言,内置持久化工作流运行时和 Azure 集成。

## 项目介绍
> **AutoGen v2/下一代。** 提供 durable workflow runtime(持久化工作流执行)、human-in-the-loop(人机协同)、多 Agent 编排和 Azure 云原生部署。
