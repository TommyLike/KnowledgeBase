# google/adk-python

> [`google/adk-python`](https://github.com/google/adk-python) · 上游贡献 · Google Agent Development Kit

## 定位
> Google 官方 Agent 开发工具包,代码优先的 Python 框架,支持构建/评估/部署 AI Agent。与 Vertex AI 和 Google Cloud 深度集成。

## 项目介绍
> **Google 多语言 Agent 工具包。** 支持 Python/Java/Go/JS/C#/Rust 六种语言 SDK,内置评估框架、A2A 协议支持和生产部署工具。

## 技术栈
Python, Java, A2A Protocol, Google Cloud
