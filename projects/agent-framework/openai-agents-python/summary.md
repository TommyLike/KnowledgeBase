# openai/openai-agents-python

> [`openai/openai-agents-python`](https://github.com/openai/openai-agents-python) · 上游贡献 · OpenAI 官方多 Agent 工作流框架

## 定位
> OpenAI 推出的轻量级 Agent SDK,围绕四大原语(Agent/Handoff/Guardrail/Tracing)构建,是 Swarm 的生产级继任者。团队关注其作为 OpenAI 生态的官方 Agent 标准。

## 项目介绍
> **OpenAI 多 Agent 编排框架。** 支持 agent 间 handoff(任务移交)、guardrail(输入/输出安全检查)、tracing(全链路追踪)。内置 sandbox 执行和 code mode,配合 GPT 模型使用。

## 技术栈
Python, OpenAI API
