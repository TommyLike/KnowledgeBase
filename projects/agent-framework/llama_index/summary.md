# run-llama/llama_index

> [`run-llama/llama_index`](https://github.com/run-llama/llama_index) · 上游贡献 · 文档 Agent 与 RAG 编排平台

## 定位
> RAG(检索增强生成)领域的标杆框架。提供从文档解析、索引构建到 Agent 编排的完整 RAG 栈。

## 项目介绍
> **文档 Agent 平台。** 支持 160+ 数据源连接器,多种索引策略(向量/树/关键词/知识图谱),Agent 编排层可组合多个检索步骤完成复杂问答任务。

## 技术栈
Python, TypeScript, 向量数据库
