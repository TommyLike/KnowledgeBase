# pytorch/extension-cpp

> [`pytorch/extension-cpp`](https://github.com/pytorch/extension-cpp) · 上游贡献 · PyTorch C++ 扩展开发示例

## 定位
> PyTorch C++ 扩展开发的官方参考。展示如何用 C++/CUDA 编写自定义算子,并通过 torch.utils.cpp_extension 集成到 PyTorch 中。

## 项目介绍
> **C++/CUDA 自定义算子模板。** 提供 LLTM(Long Long Term Memory)等示例,演示 PyTorch C++ 扩展的最佳实践:CMake 配置、CUDA kernel 编写、Python 绑定。

## 技术栈
C++, CUDA, CMake, Python
