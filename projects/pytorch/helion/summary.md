# pytorch/helion

> [`pytorch/helion`](https://github.com/pytorch/helion) · 上游贡献 · Python DSL 编写高性能 ML Kernel

## 定位
> Meta 提出的 Python 嵌入式 DSL,用于编写高效可扩展的机器学习算子,目标是替代手写 CUDA/Triton kernel 的繁琐工作流。

## 项目介绍
> **Python-native 的高性能 Kernel 编写工具。** 通过 Python DSL 描述计算逻辑,自动生成优化的 GPU kernel,支持自动调优和跨平台可移植性。

## 技术栈
Python, CUDA
